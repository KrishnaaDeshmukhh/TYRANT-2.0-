# TYRANT Reboot — Decisions

Status: ACTIVE

## 2026-09-06 — Content Portfolio

### DECIDED — KEEP: Clipping / Repurposed Content

Long-form content is transformed into retention-oriented short-form clips. It can support both owned channels and a creator clipping-service business.

### DECIDED — KEEP: AI-Original Storytelling

Use original narrative formats with **Mode A only**: reusable Minecraft gameplay + voiceover + attention-grabbing visuals/captions. Do not record gameplay for every video.

### EXPLORING / KEEP: AI-Original Explainer / Educational

Keep investigating from-scratch explanation formats. Candidate visuals include gameplay, generated visuals/graphics, and illustrated/stickman treatment.

### CONDITIONAL / EXPLORING: AI Avatar / Presenter

The user can be the real face/presenter. The format is only worth keeping if high-quality editing and motion graphics can be automated sufficiently. The avatar itself is not the core difficulty.

### DECIDED — KEEP: Animated Explainer / Commentary

Keep illustrated/stickman animation as a production format. Simple AI-directed animation is considered practical enough for TYRANT and avoids the complexity of fully automated 3D animation.

### DECIDED — REJECT: Screen-recorded / Demonstration Content

Rejected because reliable UI/browser automation, changing interfaces, application state, and correction handling add complexity without sufficient strategic advantage.

### DECIDED — KEEP: List / Ranking / Recommendation Content

Keep “Top X”, ranking, comparison, recommendation, and buying-guide formats. Strong fit for affiliate monetization across AI, technology, software, and physical products. Visuals can combine logos, screenshots, product images, short demonstrations, generated visuals, simple animation, and optional reusable gameplay.

## Process Decision

Continue evaluating one content type at a time. Final architecture should be derived from the confirmed portfolio and shared capabilities, not designed in advance around assumptions.
