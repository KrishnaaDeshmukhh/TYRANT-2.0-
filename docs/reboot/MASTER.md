# TYRANT Reboot — Master

Status: ACTIVE

## What TYRANT Is

TYRANT is a private autonomous content factory designed to produce profitable social-media content at scale. The reboot expands the original clipping concept into multiple reusable content formats.

## Confirmed Portfolio

| Type | Status |
|---|---|
| Clipping / Repurposed Content | DECIDED — KEEP |

| AI-Original Explainer / Educational | EXPLORING / KEEP |

| Animated Explainer / Commentary | DECIDED — KEEP |

| List / Ranking / Recommendation | DECIDED — KEEP |

## Confirmed Format Decisions

- Storytelling uses reusable Minecraft gameplay + voiceover + attention-grabbing visuals/captions. No new gameplay recording per video.
- Animated explainers can use simple AI-directed stickman/illustrated animation rather than full 3D animation.
- List/ranking/recommendation content is a strong affiliate-oriented format. Visuals can combine product/tool assets, screenshots, generated visuals, simple animation, and optional gameplay.
- AI presenter content is conditional on automating the difficult editing/motion-graphics layer to acceptable quality. The user can be the real face/presenter.
- Screen-recorded demonstrations are rejected for now because their automation complexity is not justified.

## Architecture Direction

Use reusable jobs/workers and a shared Visual Director rather than one rigid pipeline per niche. Research, scripting, visual planning, asset generation/collection, voice, editing, QA, distribution, analytics, and monetization should be reusable capabilities.

## Economic Direction

Social-media-first, high-output, zero-cost-first. Free/open-source tools, free API credits, cloud credits, and free GPU allocations are preferred initially. Revenue can later be reinvested into paid compute and better infrastructure.

## Current Work

Continue evaluating content types one at a time. Do not prematurely lock the final architecture or build order until the portfolio is sufficiently defined.
